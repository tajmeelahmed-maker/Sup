# Excel Data Analysis Project | Data Technician Bootcamp

## 📊 Project Overview
As part of the **Data Technician Bootcamp**, I completed a series of practical Excel exercises focused on analysing retail and sales datasets. The project involved cleaning, organising, analysing, and visualising data to generate meaningful business insights using a variety of Excel tools and functions. The exercises helped develop core data analysis skills commonly used in industry. Based on tasks completed in Data_Technician_Workbook_Week_1_Excel.docx. 【1-e10226】

## 🛠 Skills Demonstrated

### Data Analysis & Excel Functions
- `SUM()` - Calculated total sales and commissions.
- `SUMIF()` - Aggregated values based on specific criteria.
- `AVERAGE()` - Calculated average sales and commission values.
- `AVERAGEIF()` - Generated conditional averages for targeted analysis.
- `DATE()`, `MONTH()`, `YEAR()` - Extracted and analysed date-related information.
- `UNIQUE()` - Identified distinct values within datasets.
- `VLOOKUP()` - Retrieved and matched data across tables.
- `SWITCH()` - Categorised sales volumes into business-defined groups (High, Medium, Low). 【1-e10226】

### Data Management
- Applied **sorting** techniques to organise records efficiently.
- Used **filters** to explore and analyse subsets of data.
- Maintained data integrity while transforming and reviewing large datasets. 【1-e10226】

### Pivot Tables
- Created PivotTables to summarise sales data by:
  - County
  - Product
  - Customer demographics
  - Sales performance
- Analysed trends and identified key business insights from summarised datasets. 【1-e10226】
